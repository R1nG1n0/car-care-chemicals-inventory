## 1. Принципы

1. **Остаток — главное на экране.** Число остатка самое крупное в карточке, набрано Unbounded. Всё остальное подчинено ему.
2. **Брутально, но не кричаще.** Толстые рамки, жёсткие тени без размытия, наклейки — это характер. Неоновых цветов нет: категории окрашены глубокими приглушёнными тонами.
3. **Цвет несёт смысл.** У категорий постоянные цвета. Терракотовый означает только «мало / ошибка», горчичный — только главное действие на экране.
4. **Палец, а не курсор.** Интерфейс рассчитан в первую очередь на телефон: зона нажатия от 44 px, поле ввода 16 px (iOS не зумирует), главные действия внизу экрана.
5. **Одна система — две темы.** Светлая и тёмная отличаются только поверхностями, текстом и рамками. Цвета категорий и действий общие.

### 2.3. Отступы, форма, тени

- **Отступы** — шаг 4 px: 4, 8, 12, 16, 20, 24, 32, 40 (`--sp-1…--sp-10`).
- **Зоны нажатия**: не меньше 44 px (`--tap`), у кнопок количества — 48 px (`--tap-lg`). Видимый элемент может быть меньше (квадрат отметки 24 px), но зона вокруг него — 44.
- **Рамки**: основная 2 px, у чипов 1,5 px.
- **Скругления**: чип 6, контрол 8, карточка 12, шторка 20.
- **Тени** — смещение без размытия:
  - `--sh-sm` 2 px — мелкие кнопки, поля;
  - `--sh-md` 3 px — кнопки, поиск;
  - `--sh-lg` 4 px — карточки, списки;
  - `--sh-key` 3 px цветом `--shadow-key` — главная кнопка и активный раздел.

### 2.4. Движение

Правила взяты из навыка `emil-design-eng`.

| Что | Как | Длительность |
|---|---|---|
| Нажатие | Элемент вдавливается в свою тень: `translate(3px,3px)`, тень исчезает | 120 мс, `--ease-out` |
| Наведение (только мышь) | Тень вырастает на 1 px | 120 мс |
| Шкала остатка | Заполняется слева один раз при открытии экрана | 700 мс, `--ease-out` |
| Шторка расхода | Выезжает снизу | 280 мс, `--ease-drawer` |
| Свайп карточки | Карточка следует за пальцем, отпущенная — возвращается или открывает расход | 280 мс, `--ease-drawer` |
| Поиск, фильтры, кнопки ±, ввод с клавиатуры | **Без анимации**: эти действия делаются десятки раз подряд | — |

При `prefers-reduced-motion` движение отключается, остаются только смены цвета.

## 4. Паттерны

- **Главная.** Поиск сверху, фильтры-чипы, карточки позиций в одну колонку на телефоне и в две на компьютере. Свайп влево по карточке открывает расход этой позиции. На компьютере справа панель выбранной позиции с расходом, выбранная карточка выделена.
- **Расход.** Шторка снизу:
  - переключатель «Одна позиция / Шаблон»;
  - поле количества с подставленным прошлым значением и кнопками;
  - выбор экземпляра (по умолчанию вскрытый);
  - горчичная кнопка «Списать».
  
  После списания появляется уведомление с «Отменить».
- **Шаблон.** Строки «позиция — количество» с компактными кнопками ±. Если позиции не хватает, строка подсвечивается терракотовым. Внизу итог: себестоимость.
- **Формы** (покупка, позиция). Одна колонка, подписи над полями. Главная кнопка внизу, на телефоне закреплена над клавиатурой.
- **Редактируемые списки** (места, категории):
  - ручка перетаскивания слева;
  - название меняется прямо в строке по нажатию;
  - справа число экземпляров;
  - архивирование — в меню строки.
- **Пустые состояния.** Приглашение к действию, а не извинение: «Добавьте первую покупку — остатки появятся сами» + кнопка.

## 5. Правила

| Делать | Не делать |
|---|---|
| Одна горчичная кнопка на экран | Две главные кнопки рядом или в меню и на экране одновременно |
| Крупно — общий остаток, вскрытая бутылка — подписью | Разные числа крупно на разных экранах |
| Зона нажатия от 44 px, кегль от 12 px | Кнопки 32–36 px, подписи 11 px |
| Список действий — строки целиком нажимаются | Одинаковые акцентные кнопки в каждой строке |
| «Мало» — цветом **и** словом / наклейкой | Сообщать о нехватке только цветом |
| Цвет категории — только из восьми токенов | Произвольные цвета у категорий |
| Числа остатка — Unbounded, текст — Manrope | Unbounded в абзацах и подписях |
| Тени только жёсткие, со смещением | Размытые тени, градиенты, свечение |
| Анимация только при редких событиях | Анимация поиска, фильтров, кнопок ± |
| Тексты по-деловому: «Списать», «Сохранить», «Нет в наличии» | «Пожалуйста», «Успешно!», восклицательные знаки в системных сообщениях |

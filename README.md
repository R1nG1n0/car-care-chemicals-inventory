# garage

Личный учёт автохимии и инструментов детейлинга. В приложении видно, что есть дома, где лежит, сколько осталось и что пора купить. Ещё в нём хранится история покупок: сколько, где, когда и почём.

Сайт работает на VPS `relay` и открывается только через VPN: https://garage.north-flow.online. У каждого пользователя свой независимый склад. Владелец приглашает друзей ссылкой. На телефоне сайт ставится на главный экран как приложение (PWA).

## Что умеет (v1.0)

- **Позиции** двух видов: бутылки учитываются в мл, инструменты (микрофибры, губки, аппликаторы, щётки) — в штуках. У позиции есть категория, бренд, объём упаковки, минимальный остаток и штрихкод.
- **Покупки** из нескольких строк: магазин, дата, цена за упаковку. Каждая упаковка становится отдельным экземпляром со своим местом. В карточке позиции — история цен и магазинов.
- **Места хранения**: коробки, полки, пакеты. Их можно переименовывать, переставлять и убирать в архив. Экземпляры можно перемещать между местами.
- **Расход** тремя способами:
  - число вручную;
  - кнопки −50/−10/+10/+50, для штук −1/+1/+5;
  - шаблоны, например «Мойка» из нескольких позиций, которые списываются одним нажатием и показывают себестоимость.

  Сначала расходуется вскрытая бутылка, затем следующая. Поле подставляет прошлое количество.
- **Отмена** любого движения в течение 10 секунд кнопкой в уведомлении, позже — удалением из журнала. Остаток при этом пересчитывается. Ещё есть корректировка остатка и списание с причиной.
- **Главный экран**: поиск по названию, бренду и штрихкоду, фильтры «мало», «нет», «в наличии», по категории и месту. На телефоне свайп по карточке открывает расход.
- **Список покупок**: позиции ниже минимума с последней ценой и магазином, плюс ручные пункты.
- **Интерфейс «Сумерки»**: тёмная и светлая темы, версии для телефона и компьютера, анимации с учётом настройки «уменьшить движение».

## v1.1–v1.2

- **Сканер штрихкодов** камерой телефона: найденный код открывает позицию, незнакомый — создать позицию или привязать код к существующей; сканер и в форме позиции.
- **Инвентаризация** места хранения: на месте / исправить остаток / нет на месте / в другом месте, одинаковые запечатанные — одной строкой; отметка «проверено ДД.ММ».
- **Отчёты**: расходы на покупки по категориям, магазинам и месяцам; расход, списания и корректировки с себестоимостью; график цены в карточке позиции.
- **Экспорт и импорт**: все данные одним JSON (с фото или без), таблицы CSV для Excel; загрузка своего файла в пустой склад.
- **Фото позиции**: снять или выбрать из галереи, сжимается в браузере, хранится в базе и попадает в ночную копию.

## v1.3 — Telegram-бот

- **Привязка**: «Ещё → Профиль → Telegram» → одноразовая ссылка на бота. Каждый видит в боте только свой склад, чужим бот не отвечает.
- **Остаток**: напишите название — бот покажет остаток и место; цифры штрихкода или его фото — найдёт позицию.
- **Расход**: «шампунь 50» или кнопки в карточке позиции, с кнопкой «Отменить».
- **Список покупок** (`/list`): «Куплено» вычёркивает ручной пункт, а у позиции ниже минимума записывает покупку (упаковки, цена, магазин и место как в прошлый раз).
- **Уведомление**, когда остаток опускается ниже минимума — одно на каждое пересечение.

Бот сам опрашивает Telegram, входящих подключений нет: сайт по-прежнему доступен только из VPN. Подробности — [ТЗ](docs/TZ_uchet_avtohimii.md), ФТ-11.

## v1.4 — расход без связи

- Без VPN приложение открывается (сервис-воркер хранит файлы интерфейса) и показывает последние остатки с пометкой «данные на …».
- Расход и шаблоны без связи записываются в очередь на телефоне, остаток сразу уменьшается. Когда VPN появится, записи уходят сами; повтор не спишет дважды, время расхода — с телефона.
- Если на складе уже не хватает, запись ждёт решения в «Ещё → Неотправленное»: изменить количество, списать сколько есть или удалить.
- Покупки, перемещения и правки — только со связью. Выход из аккаунта стирает сохранённые данные и очередь.

## v1.5 — карточка средства

- **Назначения** — свой справочник («Ещё → Справочники → Назначения»), у позиции их может быть несколько. Поиск «кожа» находит всё для кожи, на главной — фильтр по назначению.
- **О средстве**: pH, «Не смешивать с» (предупреждение), инструкция.
- **Оценка** звёздами и «Не брать больше» прямо в карточке. Такие позиции не попадают в список покупок, бот не напоминает о них и не предлагает их как аналог.
- **Аналоги**: когда средство кончилось или его мало — «Есть дома для того же» в карточке, в списке покупок и в уведомлении бота.

## v1.8 — погода

- Прогноз Open-Meteo на 7 дней (запрашивает сервер, браузер к внешним сайтам не ходит). Город по умолчанию — в профиле (без выбора — Донецк из настроек сервера). На экране «Погода» можно посмотреть любой другой город, не меняя город по умолчанию, и одной кнопкой сделать его основным.
- Оценка дня для мойки и для покрытия (воск, керамика): хорошо / так себе / плохо, с причиной («дождь завтра в 01:00», «холодно +3° весь день»).
- Плашка на главной с подсказкой лучшего дня, экран «Погода» с днями и часами, команда бота `/weather`. Без связи — последний сохранённый прогноз.

## Разработка

Нужны Go 1.26 и Node.js с npm.

```bash
make dev
```

Сервер запускается на тестовых данных из `.dev/`, Vite — с горячей перезагрузкой. Открывать http://localhost:5173. Перед первым входом нужно создать пользователя:

```bash
go run ./cmd/garage -config config/dev.json user add <логин>
```

Другие цели:

| Команда | Что делает |
|---|---|
| `make test` | `go vet`, gofmt, Go-тесты, проверка типов, ESLint, Vitest |
| `make web` | зависимости по `package-lock.json`, проверки и сборка интерфейса в `web/dist` |
| `make build` | бинарник под текущую систему (`bin/garage`) |
| `make run` | бинарник со встроенным интерфейсом на тестовых данных, http://localhost:8090 |
| `make build-linux` | статический бинарник для relay (`bin/garage-linux-amd64`) |
| `make deploy HOST=relay` | выкладка на сервер и перезапуск службы |

Если после `npm install <пакет>` Go-тесты начинают заходить в `web/node_modules`, выполните `node web/scripts/node-modules-gomod.mjs`. `make web` делает это сам.

## Безопасность

- Доступ только из VPN: nginx слушает адрес VPN, приложение — только `127.0.0.1`.
- Пароли хранятся как argon2id. Токены сессий и приглашений лежат в базе только в виде хешей.
- Cookie `HttpOnly`, `Secure`, `SameSite=Strict`. Изменяющие запросы требуют заголовок `X-Requested-With: garage`.
- После 5 неверных паролей за 15 минут вход закрывается на 15 минут, отдельно по логину и по адресу.
- Строгая CSP без inline-скриптов и внешних адресов, шрифты свои. Сервис-воркер хранит только файлы интерфейса, ответы API не кэширует.
- Токен бота — только в `/etc/garage/config.json`, в журнал не попадает. Сохранённые для работы без связи данные и очередь стираются при выходе из аккаунта.
- Каждый запрос работает только с данными своего пользователя. Чужие id отвечают 404, это проверяется автотестом по всем адресам API.
